# 🖱️ АвтоКликер

**АвтоКликер** — это лёгкая программа для автоматического кликанья мышью с высокой скоростью. Она позволяет имитировать клики каждые **0,1 секунды**. Подходит для игр, тестирования или автоматизации повторяющихся действий.

---

## ⚙️ Возможности

- **Сверхбыстрые клики** – каждые **0,1 секунды**
- **Простое управление** – включение/отключение одной горячей клавишей
- **Лёгкость** – минимальное потребление ресурсов системы
- **Не требует установки** – просто запустите исполняемый файл

---

## 🚀 Как использовать

1. **Запустите от имени Администратора**  
   Для корректной работы программе требуются права администратора.  
   Нажмите правой кнопкой мыши на файл `autocliker.exe` и выберите **"Запуск от имени администратора"**.

2. **Включение / Отключение**  
   Нажмите следующую комбинацию клавиш для активации или деактивации автокликера:  

> ⚠️ **Важно:** Клавиша `Ё` работает **независимо от раскладки клавиатуры**.  
> Даже если у вас установлен английский язык, нажатие `Ё` всё равно активирует инструмент.

3. **Остановка программы**  
Чтобы полностью закрыть приложение:  
- Откройте **Диспетчер задач** (`Ctrl + Shift + Esc`)  
- Найдите процесс с именем **`autocliker`**  
- Выделите его и нажмите **"Снять задачу"**

---

## ⚠️ Важные замечания

- **НЕ МЕНЯЙТЕ имя исполняемого файла** — иначе программа **не запустится**.
- Всегда запускайте программу **от имени Администратора**.
- Программа предназначена только для **Windows**.

---

---

## ❓ Часто задаваемые вопросы

**В: Почему нужны права администратора?**  
О: Программа имитирует системные события ввода, что требует повышенных привилегий в Windows.

**В: Можно ли изменить горячую клавишу?**  
О: На данный момент горячая клавиша зафиксирована как `Shift + Alt + Ё` и не настраивается.

**В: Это безопасно?**  
О: Да, программа только имитирует клики мыши и не изменяет системные файлы и не собирает данные пользователя.
